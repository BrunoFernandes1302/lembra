      Em quantos caracteres cada memória é quebrada. Menor = busca mais precisa, mas cada pedaço tem menos contexto. Maior = mais contexto, busca mais "genérica".
      
            
      
            
      
              
              
              
      Quanto do fim de um pedaço se repete no começo do próximo, para não perder informação na "fronteira". Só funciona quando o texto quebra em partes menores que esse valor (frases curtas).
      
            
      
            
      
              
              
              
      Quantos pedaços a busca entrega para a IA. Poucos = pode faltar informação. Muitos = mais ruído e mais lento.
      
            
      
            
      
              
              
              
      Sem IA, mostra só trechos com nota até essa distância da melhor. 0 = só o melhor; maior = mostra mais.
      
            
      
            
            
      Desligado: o Lembra só mostra as memórias encontradas (grátis, nada vai para a IA).
      
            
            
            
      
            
      
            
          
      
          
      
            
      Reprocessar memórias
      
            
      Mudou o tamanho do chunk ou a sobreposição? As memórias antigas continuam quebradas do jeito antigo até você reprocessar. O texto original nunca muda; só os pedaços e vetores são refeitos.
